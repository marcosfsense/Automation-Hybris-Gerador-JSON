┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 LISTAR TODOS OS USUÁRIOS                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  python manage_users.py list

  Resultado: Mostra todos os usuários cadastrados com:
             - Nome do usuário
             - Status (ativo/inativo)
             - Data de criação
             - Último acesso


┌──────────────────────────────────────────────────────────────────────────────┐
│ ➕ ADICIONAR NOVO USUÁRIO                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  python manage_users.py add <username> <password>

  Exemplos:
    python manage_users.py add joao Senha@Joao2024
    python manage_users.py add maria MariaSense#2024
    python manage_users.py add carlos Carlos@Project123

  Requisitos:
    - Username: mínimo 3 caracteres
    - Password: mínimo 8 caracteres


┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔑 ALTERAR SENHA DE UM USUÁRIO                                               │
└──────────────────────────────────────────────────────────────────────────────┘

  python manage_users.py change <username> <new_password>

  Exemplos:
    python manage_users.py change marco SenhaNovaForte2024!
    python manage_users.py change joao NovaSenha@Joao
    python manage_users.py change maria Projeto#2024


┌──────────────────────────────────────────────────────────────────────────────┐
│ ❌ REMOVER UM USUÁRIO                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  python manage_users.py remove <username>

  Exemplos:
    python manage_users.py remove joao
    python manage_users.py remove carlos
    python manage_users.py remove maria

  ⚠️  CUIDADO: Usuário removido não pode mais logar!


┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔄 RESETAR PARA CONFIGURAÇÃO PADRÃO                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  python manage_users.py reset-all

  Efeito:
    - Remove TODOS os usuários
    - Mantém apenas 'marco'
    - Resetar para senha padrão: SenhaForte123!Marcos

  ⚠️  AVISO: Esta ação não pode ser desfeita! Use com cuidado!

╚══════════════════════════════════════════════════════════════════════════════╝

ERRO: "Usuário já existe"
──────────────────────────

  Causa: Tentou criar um usuário que já existe

  Solução:
    ➡️  Use nome diferente: python manage_users.py add usuario2 Senha123!
    ➡️  Ou altere a senha: python manage_users.py change username NovaSenha


ERRO: "Senha deve ter pelo menos 8 caracteres"
───────────────────────────────────────────────

  Causa: Senha muito curta

  Solução:
    ➡️  Use senha com 8+ caracteres
    ➡️  Exemplo: python manage_users.py add user Senha@User2024


ERRO: "Usuário não encontrado"
────────────────────────────────

  Causa: Tentou editar/remover usuário que não existe

  Solução:
    ➡️  Verifique o nome: python manage_users.py list
    ➡️  Certifique-se da digitação (maiúsculas/minúsculas importam)


ERRO: FileNotFoundError ou credentials.json vazio
───────────────────────────────────────────────────

  Causa: Arquivo foi deletado ou corrompido

  Solução:
    ➡️  Execute qualquer comando para recriar:
    ➡️  python manage_users.py list
    ➡️  Ou use reset-all para restaurar padrão

╚══════════════════════════════════════════════════════════════════════════════╝

Após modificar usuários, siga este processo:

1️⃣  Fazer commit local
─────────────────────

  git add credentials.json
  git commit -m "chore: Adicionar/alterar/remover usuario"


2️⃣  Push para GitHub
────────────────────

  git push origin main


3️⃣  Redeploy no Coolify
───────────────────────

  1. Abra: https://coolify.sensebike.com.br
  2. Navegue: Gerador-JSON-Hybris → Deployments
  3. Clique: "Redeploy" (botão vermelho)
  4. Aguarde: ~1-2 minutos


4️⃣  Testar novo usuário
────────────────────────

  1. Abra: https://gerajson.sensebike.com.br
  2. Teste login:
     - Usuário: <novo usuario>
     - Senha: <sua senha>
  3. Deve aparecer a tela de login
  4. Após login, acessa a aplicação
