CONFIGURAÇÃO PASSO A PASSO NO COOLIFY:
═══════════════════════════════════════════════════════════════════════════════

1. Entre em seu Coolify
2. Selecione seu aplicativo (Gerador JSON Hybris)
3. Clique na aba "Variables" ou "Environment"
4. Clique em "+ Add Variable" (ou "Add Environment Variable")
5. Para CADA linha acima:
   - Nome: [texto antes do =]
   - Valor: [texto depois do =]
   - Clique em "Add"
6. Clique em "Save" ou "Deploy"

POR QUÊ CADA VARIÁVEL:
═══════════════════════════════════════════════════════════════════════════════

STREAMLIT_SERVER_PORT=8501
└─ Define a porta que Streamlit vai usar (padrão)

STREAMLIT_SERVER_ADDRESS=0.0.0.0
└─ Permite acesso externo (necessário para Coolify)

STREAMLIT_SERVER_HEADLESS=true
└─ Modo sem interface gráfica (servidor não tenta abrir navegador)

PYTHONUNBUFFERED=1
└─ Python mostra logs em tempo real (crucial para debug no Coolify)

STREAMLIT_LOGGER_LEVEL=info
└─ Define nível de detalhamento dos logs

STREAMLIT_CLIENT_TOOLBAR_MODE=minimal
└─ Interface mais limpa (sem botões desnecessários)

STREAMLIT_CLIENT_SHOW_ERROR_DETAILS=false
└─ Não expõe detalhes técnicos de erro para usuários

PYTHONIOENCODING=utf-8
└─ Garante que caracteres especiais (como ç, ã) funcionem

DÚVIDAS COMUNS:
═══════════════════════════════════════════════════════════════════════════════

P: Preciso de todas as variáveis?
R: NÃO. As primeiras 4 (OBRIGATÓRIO) são suficientes. As outras são melhorias.

P: Posso usar porta diferente de 8501?
R: SIM, mas mantenha como 8501 no Coolify. Ele fará o mapeamento externo.

P: E se esquecer de adicionar PYTHONUNBUFFERED?
R: O app funciona, mas você não verá os logs em tempo real (dificulta debug).

P: Preciso de database ou storage?
R: NÃO. Esta aplicação não usa banco de dados, tudo é em memória.

P: Como testar se funcionou?
R: Acesse a URL pública do Coolify e teste colando um JSON de exemplo.
