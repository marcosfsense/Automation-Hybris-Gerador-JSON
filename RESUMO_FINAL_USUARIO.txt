🚀 COMO USAR
================================================================================

INICIAR O APLICATIVO:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Windows:
  Clique duplo em: executar_app.bat

Linha de comando (qualquer SO):
  python -m streamlit run src/app_streamlit.py

O navegador abrirá automaticamente em: http://localhost:8501


USAR O APLICATIVO:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Cole o JSON do cabeçalho (obtido no Hybris)
2. Selecione o tipo de transação
3. Preencha os campos (manual) OU Cole JSON (pré-preenchimento)
4. Clique "🚀 Gerar JSON"
5. Veja o resultado
6. Copie ou baixe o JSON

PARA MÚLTIPLAS:
- A Seção 2.1 aparece para pré-preenchimento
- Ou clique "Não" para formulários manuais em cada aba
- Cada aba tem pergunta individual "Já existe a transação?"
