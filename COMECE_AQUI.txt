=================================================================
 🎯 COMECE AQUI - 3 PASSOS SIMPLES
=================================================================

PASSO 1: Verifique se tem Python
────────────────────────────────

Windows:
  a) Abra o Menu Iniciar
  b) Digite: cmd
  c) Digite: python --version

  Se vir "Python 3.x.x" → Pule para PASSO 2
  Se der erro → Execute o instalador automático


PASSO 2: Instale Python (SE NECESSÁRIO)
───────────────────────────────

Se não tem Python:
  1) Duplo clique em: instalar_python.bat
  2) Siga as instruções na tela
  3) Aguarde 3-5 minutos

Se já tem Python:
  Pule para PASSO 3


PASSO 3: Inicie a Aplicação
──────────────────────────

  1) Duplo clique em: executar_app.bat
  2) Aguarde a aplicação abrir
  3) O navegador abrirá automaticamente

=================================================================
 💻 PARA USUÁRIOS TÉCNICOS
=================================================================

Manual (sem instalador automático):

1. git clone https://github.com/marcosfsense/AUTOMA--O-HYBRIS---GERADOR-DE-JSONs.git
2. cd AUTOMA--O-HYBRIS---GERADOR-DE-JSONs
3. pip install -r requirements.txt
4. streamlit run src/app_streamlit.py

Executável portátil (sem Python):

1. executar criar_executavel.bat
2. Arquivo criado em: dist_app/Gerador_JSON_Hybris.exe
