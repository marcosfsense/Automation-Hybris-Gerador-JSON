📋 COMANDOS PRINCIPAIS
═════════════════════════════════════════════════════════════════════════════

1️⃣  LISTAR USUÁRIOS ATUAIS
───────────────────────────────────────────────────
Comando:
  python manage_users.py list

Resultado:
  ============================================================
  📋 USUÁRIOS CADASTRADOS
  ============================================================

  👤 marco
     Status: ✅ Ativo
     Criado em: 2024-11-26
     Último acesso: None

  ============================================================


2️⃣  CRIAR NOVO USUÁRIO
───────────────────────────────────────────────────
Comando:
  python manage_users.py add joao Senha@Joao2024

Resultado:
  ✅ Usuário 'joao' criado com sucesso!

Explicação:
  - 'joao' = nome do usuário
  - 'Senha@Joao2024' = senha (mínimo 8 caracteres)


3️⃣  ALTERAR SENHA DE UM USUÁRIO
───────────────────────────────────────────────────
Comando:
  python manage_users.py change marco SenhaNovaForte2024!

Resultado:
  ✅ Senha do usuário 'marco' alterada com sucesso!

Explicação:
  - 'marco' = nome do usuário (já deve existir)
  - 'SenhaNovaForte2024!' = nova senha


4️⃣  REMOVER UM USUÁRIO
───────────────────────────────────────────────────
Comando:
  python manage_users.py remove joao

Resultado:
  ✅ Usuário 'joao' removido com sucesso!

Explicação:
  - 'joao' = nome do usuário a remover
  - Usuário não poderá mais acessar a aplicação


5️⃣  RESETAR PARA PADRÃO
───────────────────────────────────────────────────
Comando:
  python manage_users.py reset-all

Resultado:
  ⚠️  Tem certeza? Isso removerá TODOS os usuários (exceto 'marco')! (s/n):
  Responda: s

  ✅ Credenciais resetadas para configuração padrão!

Explicação:
  - Remove TODOS os usuários
  - Mantém apenas 'marco' com senha padrão
  - Use apenas em emergências!

🔐 DICAS DE SEGURANÇA
═════════════════════════════════════════════════════════════════════════════

✅ BOAS PRÁTICAS
─────────────────
  ✓ Altere a senha padrão assim que tiver acesso
  ✓ Use senhas com 12+ caracteres (quanto mais longa, melhor)
  ✓ Misture letras, números e símbolos (!@#$%^&*)
  ✓ Nunca reutilize a mesma senha para várias contas
  ✓ Compartilhe senhas apenas via canais seguros (WhatsApp, Slack privado)

❌ NÃO FAÇA
────────────
  ✗ Não edite o arquivo credentials.json manualmente
  ✗ Não compartilhe senhas por email
  ✗ Não use senhas simples (123456, senha123, etc)
  ✗ Não commit credentials.json com dados reais no GitHub público
  ✗ Não deixe senhas em textos abertos


📊 COMO O ARQUIVO credentials.json FUNCIONA
═════════════════════════════════════════════════════════════════════════════

As senhas são armazenadas de forma SEGURA:

ANTES (você digita):
  Usuário: marco
  Senha: SenhaForte123!Marcos

DURANTE (o app processa):
  1. App gera hash: sha256:a43f1d0aafd193734f329da5c1f88df67aac503afea0320db3825f2396e3e9a8
  2. App compara com o hash armazenado
  3. Se forem iguais → ✅ Acesso concedido
  4. Se forem diferentes → ❌ Acesso negado

ARMAZENADO (no arquivo):
  {
    "marco": {
      "password_hash": "sha256:a43f1d0aafd193734f329da5c1f88df67aac503afea0320db3825f2396e3e9a8",
      "created_at": "2024-11-26",
      "enabled": true
    }
  }

❌ A senha NUNCA é armazenada em texto plano!
✅ Mesmo que alguém veja o arquivo, não consegue descobrir a senha!


🔄 USANDO COM COOLIFY (DEPLOY)
═════════════════════════════════════════════════════════════════════════════

Quando você adiciona/remove/altera usuários, precisa fazer deploy:

PASSO 1: Fazer commit no GitHub
────────────────────────────────
  git add credentials.json
  git commit -m "chore: Adicionar usuario carlos"
  git push origin main

PASSO 2: Fazer redeploy no Coolify
────────────────────────────────────
  1. Abra: https://coolify.sensebike.com.br
  2. Vá para: Gerador-JSON-Hybris → Deployments
  3. Clique em: "Redeploy" (botão vermelho)
  4. Aguarde: ~1-2 minutos

PASSO 3: Testar novo usuário
──────────────────────────────
  1. Abra: https://gerajson.sensebike.com.br
  2. Teste login com novo usuário:
     - Usuário: carlos
     - Senha: SenhaForte2024!


❓ DÚVIDAS FREQUENTES
═════════════════════════════════════════════════════════════════════════════

P: Quantos usuários posso ter?
R: Ilimitado! Crie quantos forem necessários.

P: Qual o tamanho mínimo da senha?
R: 8 caracteres (mas recomendamos 12+ caracteres).

P: Posso usar letras acentuadas na senha?
R: Sim! (ex: café, açúcar, etc)

P: Preciso fazer redeploy toda vez que mudo um usuário?
R: Sim! Faça:
   git add credentials.json
   git commit -m "chore: Alterar usuarios"
   git push origin main

P: E se eu perder a senha do marco?
R: Use reset-all para voltar ao padrão:
   python manage_users.py reset-all
   Depois altere novamente.

P: Posso editar credentials.json no Notepad?
R: ❌ NÃO! Pode quebrar o arquivo JSON. Use sempre o script.
